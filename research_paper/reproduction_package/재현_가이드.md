## ⚡ 1초 재현 실행 방법 (T10-C29, T10-C46)

본 패키지의 `scripts` 디렉토리로 이동하여 아래 명령어 중 하나를 실행하십시오. 외부 패키지 설치 없이 표준 라이브러리만으로 즉시 구동됩니다.

### 방법 1: Node.js 실행
```bash
node scripts/reproduce_analysis.js
```

### 방법 2: Python 실행
```bash
python scripts/reproduce_analysis.py
```

### 재현 실행 결과 요약
- **공공 통계**: 심평원 연간 진료비 환불 결정 건수(약 4천 건, 14억 원) 및 미수령 지연율(11.8%~14.8%) 확인
- **원자료 150건 비교 검증**:
  - 미식별 입금 식별 성공률: 기존 단일 매칭 20.0% → 제안 5단계 모형 **84.0% (+64.0%p 향상)**
  - 평균 처리/잔류 일수: 기존 137.7일 → 제안 모형 **9.6일 (-128.1일 대폭 단축)**
  - 사망환자 환불금 적격 확인율: 기존 0.0% → 공공연계(안심상속) 적용 시 **80.0% (+80.0%p 향상)**
