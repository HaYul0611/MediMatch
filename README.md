## 1. 앱 핵심 정의 (BRB-C01, BRB-C03)

### 📌 앱 한 문장
> **"병원 원무과 행정 담당자가 타인명의 송금이나 사망환자 진료비 환불금을 정산할 때, 이 앱이 논문에서 규명한 '5단계 다차원 교차검증 및 안심상속 공공연계 모형'과 '5대 학술 실증 통계 캔버스 엔진'을 통해 미식별 입금을 신속히 대조하고 적법 상속권자를 다각도로 검증하여 오지급 위험을 획기적으로 낮추고 실무 착오 리스크를 최소화해 준다."**

### 📌 사용자가 할 일 4가지 (BRB-C02)
1. **[할 일 1] 정산 대기 케이스 불러오기**: 논문 3대 대표 시나리오(보호자 대납 60%, 환자 개명 20%, 사망환자 환불금 50%) 또는 연구 원자료 150건 모의 데이터셋 로드.
2. **[할 일 2] 5단계 다차원 교차검증 파이프라인 분석**: 1차 단순성명부터 5차 공공연계까지 실시간 시뮬레이션을 실행하여 식별 성공률(20% &rarr; 84.0%)과 처리 소요일수(137.7일 &rarr; 9.6일) 단축 결과 확인.
3. **[할 일 3] 5대 학술 실증 통계 및 병원 ROI 시뮬레이터 검증**: 5-Fold 교차검증, 로그정규 잔류일 분포, 4대 가설 검정, 카플란-마이어 생존분석, 다중 로지스틱 회귀 포레스트 플롯 및 대학병원 원무 결산 ROI(연간 절감액 4.12억 원, ROI 285%)를 인터랙티브 캔버스로 실시간 확인.
4. **[할 일 4] 직접 시뮬레이션 및 원무 감사 리포트 발급**: 임의의 데이터를 직접 입력하여 안전 유효성 검증(잘못된 입력에도 멈추지 않음)을 시험하고, 트랜잭션별 SHA-256 서명 직인이 날인된 결산 감사 증적 리포트를 발급/출력.

## 3. 5대 학술 실증 통계 모델 & 시각화 엔진 (`js/stats.js`)

HTML5 Canvas 기반의 고해상도(HiDPI) 자체 그래픽 엔진으로 구현되어 외부 차트 라이브러리(Chart.js 등) 종속성 없이 완전히 독립 구동됩니다.

| 번호 | 통계 모델 | 시각화 방식 | 논문 실증 핵심 수치 |
|:---:|:---|:---|:---|
| **01** | **5-Fold 교차검증 모델** | 반응형 이중 막대 차트 | Train 정확도 90.03%, Val 정확도 89.22% (일반화 격차 0.81%p) |
| **02** | **미식별 잔류일수 로그정규 분포** | 확률밀도함수(PDF) 곡선 & 히스토그램 | $\mu=4.12, \sigma=0.74$, 도입 전후 단축 기대치 128.1일 |
| **03** | **4대 핵심 가설 실증 검정** | 비교 바 차트 & 유의수준 뱃지 ($p<.001$) | 가설 1~4 전 항목 통계적 유의성 입증 ($p < 0.001$) |
| **04** | **카플란-마이어 생존분석** | 누적 잔류 확률 생존곡선 | 중위 미정산 잔류일수 138일 &rarr; 7일 단축 (Log-Rank $\chi^2=412.8$) |
| **05** | **다중 로지스틱 회귀분석** | 포레스트 플롯 (Forest Plot) | 안심상속 OR 47.00, HIS보호자 OR 30.57, BCa 95% CI 전원 유의 |
| **ROI** | **대학병원 원무 ROI 시뮬레이터** | 실시간 비용 절감 산출기 | 상급종합병원 기준 연간 절감 4억 1,200만 원, ROI 285% 달성 |

## 4. 모바일·데스크톱 반응형 뷰포트 및 가독성 설계 (`css/app.css`)

모바일(320px~768px), 태블릿(769px~1024px), 데스크톱(1025px 이상) 전 해상도에서 깨짐 없이 안정적으로 동작합니다.

* **한국어 줄바꿈 가드**: 본문 및 히어로 배너에 `word-break: keep-all; overflow-wrap: break-word;`를 전역 적용하여 어휘 분절 및 외톨이 문자 발생 방지.
* **아코디언 모바일 수직 스택**: 좁은 뷰포트에서 번호 뱃지, 제목, 상태 뱃지, 토글 아이콘이 뭉쳐 줄바꿈이 깨지지 않도록 모바일 최적화 레이아웃 적용.
* **스마트 캔버스 범례 래핑**: 좁은 화면에서 범례 텍스트가 캔버스 밖으로 잘리지 않도록 자동 줄바꿈 및 모바일 단축 레이블(`Log-Normal (모의)`) 적용.
* **터치 가로 스크롤**: 통계 테이블에 `-webkit-overflow-scrolling: touch;` 및 커스텀 스크롤바를 지원하여 표 찌그러짐 원천 차단.

## 6. 실행 방법 (BRB-C08, BRB-C09)

이 애플리케이션은 종속성 설치나 빌드 과정 없이 **새 시크릿 창 또는 새 임시 폴더에서 즉시 실행**됩니다.

### 방법 A. 브라우저로 직접 열기 (가장 간단)
1. 저장소 폴더 내 `index.html` 파일을 더블 클릭하여 웹 브라우저(Chrome, Edge 등)로 엽니다.

### 방법 B. 로컬 정적 웹 서버 실행
```bash
# Python 환경
python -m http.server 8080

# 또는 Node.js 환경
npx serve .
```
브라우저 주소창에 `http://localhost:8080/`을 입력하여 접속합니다.

### 방법 C. 무결성 종합 자동 검증 스크립트 실행
```bash
node scripts/verify_medimatch_integrity.js
```
* 논문 PDF/산출물 유효성, 다운로드 링크 무결성, 5대 캔버스 탑재, 반응형 안전 로직, CSS 가독성 가드 26개 전 항목 자동 검증.

## 9. 보안 아키텍처 및 안전 조치 (Security Architecture)

본 애플리케이션은 **SKT ALEPH 인프라/보안 엔지니어링 표준** 및 **개인정보보호법 제29조(안전조치의무)**를 준수하여 설계되었습니다.

| 보안 위협 | 대응 통제 방안 | 구현 위치 |
|:---|:---|:---|
| **XSS (Cross-Site Scripting)** | 사용자 입력값 및 업로드 데이터 DOM 렌더링 시 HTML 엔티티 완전 치환 | `PipelineEngine.escapeHtml()` |
| **CSV Injection (DDE 수식 실행)** | `=`, `+`, `-`, `@` 기호로 시작하는 악성 수식 셀 자동 접두어 무력화 | `PipelineEngine.sanitizeCsvCell()` |
| **파일 업로드 DoS & ReDoS** | 업로드 파일 크기 1MB 제한 및 행 수·타입 정밀 검증 | `app.js` 파일 검증 핸들러 |
| **개인정보 오남용 방지** | 환자 성명 및 민감 식별정보 뷰어 마스킹 시뮬레이션 토글 탑재 | `PipelineEngine.maskName()` |
| **감사 무결성 위변조 방지** | 트랜잭션별 SHA-256 서명 해시 생성 및 전자 직인 스탬프 연동 | `PipelineEngine.generateAuditHash()` |
| **비밀값 및 키 노출 방지** | 하드코딩된 API 키/토큰 0건, 무인증 완전 독립 구동 | 소스 코드 전수 점검 통과 |
