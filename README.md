## 1. 앱 핵심 정의 (BRB-C01, BRB-C03)

### 📌 앱 한 문장
> **"병원 원무과 행정 담당자가 타인명의 송금이나 사망환자 진료비 환불금을 정산할 때, 이 앱이 논문에서 규명한 '5단계 다차원 교차검증 및 안심상속 공공연계 모형'을 통해 미식별 입금을 신속히 대조하고 적법 상속권자를 다각도로 검증하여 오지급 위험을 획기적으로 낮추고 실무 착오 리스크를 최소화해 준다."**

### 📌 사용자가 할 일 세 가지 (BRB-C02)
1. **[할 일 1] 정산 대기 케이스 불러오기**: 논문 3대 대표 시나리오(보호자 대납 60%, 환자 개명 20%, 사망환자 환불금 50%) 또는 연구 원자료 150건 모의 데이터셋 로드.
2. **[할 일 2] 5단계 다차원 교차검증 파이프라인 분석**: 1차 단순성명부터 5차 공공연계까지 실시간 시뮬레이션을 실행하여 식별 성공률(20% &rarr; 84.0%)과 처리 소요일수(137.7일 &rarr; 9.6일) 단축 결과 확인.
3. **[할 일 3] 직접 시뮬레이션 및 원무 감사 리포트 발급**: 임의의 데이터를 직접 입력하여 안전 유효성 검증(잘못된 입력에도 멈추지 않음)을 시험하고, 결산 감사 증적 리포트를 발급/출력.

## 2. 데이터 및 비밀값 관리 (BRB-C06, BRB-C07, BRB-C12)

* **개인정보 보호**: 앱에 내장된 데이터는 논문 연구에 사용된 150건의 **100% 가명 모의 데이터**(`환자1`, `보호자1` 등) 및 심평원 공공 공개 통계 데이터만 사용하며, 실제 개인정보가 일절 포함되어 있지 않습니다.
* **비밀값 관리**: 순수 브라우저 클라이언트 사이드 기술로 구현되어 서버 측 비밀번호, 토큰, API 키가 존재하지 않으며 소스 코드 및 화면 어디에도 유출 위험이 없습니다.

## 3. 실행 방법 (BRB-C08, BRB-C09)

이 애플리케이션은 종속성 설치나 빌드 과정 없이 **새 시크릿 창 또는 새 임시 폴더에서 즉시 실행**됩니다.

### 방법 A. 브라우저로 직접 열기 (가장 간단)
1. 저장소 폴더 내 `index.html` 파일을 더블 클릭하여 웹 브라우저(Chrome, Edge 등)로 엽니다.

### 방법 B. 로컬 정적 웹 서버 실행
```bash
# Python 환경
python -m http.server 8080

# 브라우저에서 열기
http://localhost:8080/
```

## 4. 확인 및 통과 기준 (BRB-C13)

| 확인 단계 | 실행 방법 | 정상 통과 기준 |
|:---|:---|:---|
| **첫 화면 확인** | `index.html` 접속 | 첫 화면 배너에 논문 제목과 "이 앱은 누구를 어떻게 돕습니다" 한 문장이 표시됨 |
| **할 일 1 실행** | 상단 '케이스 1 (보호자 대납)' 클릭 | 정산 폼에 데이터가 자동으로 입력되고 파이프라인 대기 상태로 전환됨 |
| **할 일 2 실행** | '5단계 교차검증 실행' 버튼 클릭 | 1~5단계 노드가 순차 점등되며 최종 판정 '매칭완료 진료비수납' 및 식별률 84% 갱신 |
| **할 일 3 실행** | '원무 결산 감사 리포트 발급' 버튼 클릭 | 트랜잭션 감사 증적 요약 모달이 열리며 닫기 및 인쇄 버튼이 정상 동작함 |
| **예외 방어 확인** | 금액에 `-5000` 입력 후 실행 | 앱이 멈추지 않고 "금액은 0원보다 큰 올바른 숫자여야 합니다" 경고창 표시 |

## 6. 보안 아키텍처 및 안전 조치 (Security Architecture)

본 애플리케이션은 **SKT ALEPH 인프라/보안 엔지니어링 표준** 및 **개인정보보호법 제29조(안전조치의무)**를 준수하여 설계되었습니다.

| 보안 위협 | 대응 통제 방안 | 구현 위치 |
|:---|:---|:---|
| **XSS (Cross-Site Scripting)** | 사용자 입력값 및 업로드 데이터 DOM 렌더링 시 HTML 엔티티 완전 치환 | `PipelineEngine.escapeHtml()` |
| **CSV Injection (DDE 수식 실행)** | `=`, `+`, `-`, `@` 기호로 시작하는 악성 수식 셀 자동 접두어 무력화 | `PipelineEngine.sanitizeCsvCell()` |
| **파일 업로드 DoS & ReDoS** | 업로드 파일 크기 1MB 제한 및 행 수·타입 정밀 검증 | `app.js` 파일 검증 핸들러 |
| **개인정보 오남용 방지** | 환자 성명 및 민감 식별정보 뷰어 마스킹 시뮬레이션 토글 탑재 | `PipelineEngine.maskName()` |
| **감사 무결성 위변조 방지** | 트랜잭션별 SHA-256 서명 해시 생성 및 전자 직인 스탬프 연동 | `PipelineEngine.generateAuditHash()` |
| **비밀값 및 키 노출 방지** | 하드코딩된 API 키/토큰 0건, 무인증 완전 독립 구동 | 소스 코드 전수 점검 통과 |
